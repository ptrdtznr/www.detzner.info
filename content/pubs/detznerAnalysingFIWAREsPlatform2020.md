#### Analysing FIWAREs Platform - Potential Improvements
The digitalization of the world proceeds continuously.
As part of this, we are facing a smart digital future where everything is connected and linked while we are transforming big data into knowledge.
The FIWARE platform, which is the result of a series of EU funded projects, supports this transformation.
Developers, integrators and end users are able to rapidly create new applications, by using components provided by this platform.
We have analyzed central building blocks of the FIWARE platform from different aspects and based on experiments and code reviews - identified various areas of improvements.
Our analysis also provides some recommendations for the current code base that can help to improve those FIWARE components under investigation.
